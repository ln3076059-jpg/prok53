5. KIEM CHECKSUM VA GIAI NEN
======================================================================

Mo PowerShell, sau do chay nguyen khoi lenh:

  $TrainRoot = "C:\RoadWatchV2"
  $ZipPath = Join-Path $TrainRoot "MULTIMODEL_V2_PRETRAIN_PENDING_APPROVAL_PORTABLE.zip"
  $ChecksumPath = Join-Path $TrainRoot "MULTIMODEL_V2_PRETRAIN_PENDING_APPROVAL_PORTABLE.sha256"
  $BundleRoot = Join-Path $TrainRoot "bundle"
  $Working = Join-Path $TrainRoot "runs\full"
  $SmokeWorking = Join-Path $TrainRoot "runs\smoke"
  $BackupRoot = Join-Path $TrainRoot "backup"

  if (-not (Test-Path -LiteralPath $ZipPath)) { throw "Thieu ZIP: $ZipPath" }
  if (-not (Test-Path -LiteralPath $ChecksumPath)) { throw "Thieu checksum" }

  $Expected = ((Get-Content -LiteralPath $ChecksumPath -Raw).Trim() -split '\s+')[0].ToLowerInvariant()
  $Actual = (Get-FileHash -LiteralPath $ZipPath -Algorithm SHA256).Hash.ToLowerInvariant()
  Write-Host "Expected:" $Expected
  Write-Host "Actual:  " $Actual
  if ($Actual -ne $Expected) { throw "STOP: ZIP checksum mismatch" }

  if (Test-Path -LiteralPath $BundleRoot) {
      throw "BundleRoot da ton tai. Dung thu muc moi de tranh tron file cu."
  }
  Expand-Archive -LiteralPath $ZipPath -DestinationPath $BundleRoot
  Write-Host "CHECKSUM VA GIAI NEN: PASS"

Khong sua config, manifest, dataset hoac weights ben trong bundle. Preflight se
tu choi neu bat ky file nao khong con dung SHA-256.
