# Kaggle V2 Pre-Train Workflows

This directory contains the necessary artifacts to deploy the **CURRENT EXPLORATORY V2** training pipeline to Kaggle.

**Legacy Workflows** (e.g. `MC_BOOTSTRAP_001`, `PHONE_BOOTSTRAP_001`, `MC_001`) are HISTORICAL and should not be used for V2.

Please upload the `MULTIMODEL_V2_PRETRAIN_PENDING_APPROVAL_PORTABLE.zip` as a **PRIVATE** dataset to Kaggle.
