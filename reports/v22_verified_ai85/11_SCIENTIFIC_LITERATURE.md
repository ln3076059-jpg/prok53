# Literature checked against primary sources

Sources accessed during this recovery. None of the external benchmark scores are Roadwatch results. Experiments below are proposals, not completed ablations. Dataset and weight rights require their own review; a code license does not grant media rights.

| Method / verified source | Problem, published data and metrics | Code / license / weights | Roadwatch compatibility, concrete experiment and cost |
|---|---|---|---|
| [SAHI](https://github.com/obss/sahi) | Sliced inference for small objects; detection AP/AR rather than phone-use event F1. The repository links the ICIP paper and benchmark assets. Exact benchmark split not re-audited here. | Framework-independent implementation; [license source](https://github.com/obss/sahi/blob/main/LICENSE); license text not verified in this session. Detector weights are separate assets. | Reuse existing YOLO with tiled native crops and NMS. Compare AP50/AP50-95, small-object recall, negative-frame FP and latency only with exhaustive approved box annotations. More tiles increase inference cost and duplicate proposals. Roadwatch ablation: NOT_RUN, annotation gate unresolved. |
| [ActionFormer paper](https://arxiv.org/abs/2202.07925), [official implementation](https://github.com/happyharrycn/actionformer_release) | Temporal action boundaries; THUMOS14, ActivityNet1.3 and EPIC-Kitchens100; temporal-IoU mAP. These definitions differ from the frozen onset/containment matcher. | MIT code; pretrained heads/features linked by official repository. Repository recommends at least 12GB GPU for its configurations. | Not a drop-in replacement for the 512-d ResNet GRU. Needs compatible temporal features, licensed labeled event sequences and a causal/latency policy. Proposed fixed-split boundary comparison after feature provenance and role bottlenecks are solved. Roadwatch: NOT_RUN. |
| [ByteTrack paper](https://arxiv.org/abs/2110.06864), [official code](https://github.com/hustvl/ByteTrack) | Associates high/low-score detections across frames; MOT-style tracking benchmarks and MOTA/IDF1/HOTA, not occupant-role accuracy. | MIT implementation; pretrained detector/model-zoo links in repository. Actual Roadwatch tracker speed not measured here. | Existing backend already uses ByteTrack for vehicle detections. Occupant tracking would require separate seat/role evidence and validated IDs. Proposed identity-switch/driver-retention study, preserving UNKNOWN when seat geometry is unverified. Tracking cannot establish who is driving by itself. Roadwatch occupant ablation: NOT_RUN. |
| [MixStyle paper](https://arxiv.org/abs/2104.02008), [official code](https://github.com/KaiyangZhou/mixstyle-release) | Domain generalization via feature-statistic mixing; classification/re-identification benchmarks. Reproduction must retain domain/subject splits and task-specific metrics. | MIT code. This audit did not verify a compatible Roadwatch pretrained checkpoint or an exact paper split. | Requires training-time backbone modifications; cannot alter an already frozen feature cache. Proposed authorized subject-disjoint warm-start only after preprocessing parity and label/rights gates. Extra fitting risk with just three repeatedly exposed subjects. Roadwatch: NOT_RUN. |
| [Group DRO paper](https://arxiv.org/abs/1911.08731), [official code](https://github.com/kohpangwei/group_DRO) | Worst-group generalization and regularization; includes spurious-correlation/group-shift tasks such as Waterbirds/CelebA/MultiNLI. Worst-group accuracy differs from pooled F1. | MIT implementation. No compatible Roadwatch checkpoint verified; algorithm requires fitting and explicit group definitions. | Proposed subject-group loss with fixed inner validation, reporting worst-subject SAFE/PHONE recall. Three development subjects provide weak group coverage. Requires new lawful, labeled subjects before credible generalization claims. Roadwatch: NOT_RUN. |
| [Calibration paper](https://arxiv.org/abs/1706.04599), [official temperature-scaling code](https://github.com/gpleiss/temperature_scaling) | Confidence calibration of neural classifiers; reliability/ECE/NLL and held-out calibration data. Normalized softmax alone does not prove calibration. | MIT reference implementation; a fitted temperature is specific to model/data, not a transferable action checkpoint. | Cheap fitting/inference compared with detector training, but still fitting governed by data rights. Proposed subject-separated calibration of a verified action head; compare ECE/NLL and unchanged argmax metrics. It cannot repair wrong identity or feature timing. Roadwatch calibrator: NOT_FITTED. |
| [DriveCLIP official source](https://github.com/zahid-isu/DriveCLIP) | Frame-based vision-language distracted-action recognition. Source lists DMD, StateFarm, SynDD1 and SAM-DD; class mappings differ across them and split profiles are provided. Frame classification does not establish event performance. | MIT code; model checkpoint directory/inference assets exist. Download compatibility, weight provenance and exact DMD overlap were not validated here. | CLIP features/head are incompatible with the existing ResNet512 GRU input. Proposed frozen inference only after subject-overlap, class-map, data-rights and compute checks. Larger backbone cost and subject leakage remain unresolved. Roadwatch: NOT_RUN, no weights downloaded. |
| [Vicomtech DMD source](https://github.com/Vicomtech/DMD-Driver-Monitoring-Dataset) | RGB BODY/FACE/HANDS and OpenLABEL/VCD annotations. Current public description documents a revised dataset; repository availability is not a local rights approval. | Annotation/exploration tools and dataset access information. Media terms reviewed separately; no rights flags changed here. | Local inventory confirms views per session, not camera synchronization or seat calibration. Proposed synchronization/role validation before multiview fusion. gC-14 lacks local FACE/HANDS; no DASHBOARD stream is assumed. Existing BODY diagnostics are DEVELOPMENT_ONLY; no new dataset download or fitting. |

Priority is verified role identity and checkpoint/feature timing. Neither more detections nor a larger temporal head can validate an alert attached to an unverified occupant. No external accuracy is used as a Roadwatch measurement.
